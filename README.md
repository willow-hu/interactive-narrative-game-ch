# AR城市博物馆导览 - 剧情交互游戏

## 项目简介

这是一个基于Web的剧情交互游戏Demo，专为移动端设计，用于AR城市博物馆导览项目。玩家可以通过与虚拟人物对话的方式，深入了解苏州历史文化遗迹的背景故事和文化价值。

当前版本以**苏州罗汉院双塔及正殿遗址**为背景，玩家将与慧远方丈对话，探索这座千年古迹的历史故事、建筑特色和文化价值。

## 游戏特色

- 🏛️ **历史文化教育**：通过沉浸式对话了解文物古迹
- 📱 **移动端优化**：专为智能手机交互设计
- 🎯 **树状剧情**：多分支对话系统，可自由选择感兴趣的话题
- 🎖️ **成就系统**：完整探索可解锁特殊成就
- 📚 **历史记录**：查看完整的对话历史

## 快速开始

### 运行游戏

1. **直接打开**
   ```bash
   # 在浏览器中打开 index.html 文件
   # 或使用本地服务器（推荐）
   ```

2. **使用本地服务器**（推荐）
   ```bash
   # 使用Python的简单HTTP服务器
   python -m http.server 8000
   
   # 或使用Node.js的http-server
   npx http-server
   
   # 然后在浏览器访问 http://localhost:8000
   ```

### 游戏操作

1. **开始游戏**：点击"开始游戏"按钮进入剧情
2. **对话互动**：
   - 阅读NPC的话语
   - 点击"继续"按钮查看选项
   - 选择感兴趣的话题继续对话
3. **功能按钮**：
   - **告辞**：右上角红色按钮，可随时退出游戏
   - **历史对话**：右上角蓝色按钮，查看完整对话记录
4. **分支探索**：
   - 选择"换个话题"返回上级话题
   - 探索不同分支了解更多内容
5. **成就系统**：完整探索所有对话分支可解锁"塔影千年"成就

## 游戏玩法

### 剧情结构

游戏采用树状剧情结构，包含三个主要部分：

1. **引导阶段**：了解游戏玩法和背景介绍
2. **主体剧情**：探索三个主要话题分支：
   - 寺院建成的历史故事
   - 双塔的建筑特色和技术
   - 历史文化价值和意义
3. **结局**：根据探索程度触发不同结局

### 探索机制

- **智能分支管理**：只显示未探索的选项
- **返回功能**：可以回到有未探索分支的节点
- **完整性追踪**：系统记录探索进度
- **成就解锁**：完整探索解锁特殊结局和成就

### 用户界面

- **景点名称**：左上角显示当前景点
- **对话框**：底部固定区域显示NPC对话
- **选项遮罩**：半透明黑色背景上的选项按钮
- **功能按钮**：右上角的退出和历史查看功能

## 扩展开发

### 添加新景点

1. **创建脚本文件**：在`game_scripts/`目录下添加`{景点名}.json`
2. **准备图片资源**：在`imgs/`目录下创建`{景点名}/`文件夹，包含：
   - `bg.png`：背景图片
   - `npc.png`：NPC图片
3. **修改配置**：在`config.js`中设置`siteName`或使用URL参数

### 脚本格式

游戏脚本采用JSON格式，包含以下部分：

```json
{
  "metadata": {
    "site_name": "景点名称",
    "role": "NPC角色名",
    "achievement": "成就名称"
  },
  "intro": {
    // 引导对话
  },
  "main_game": {
    // 主体剧情分支
  },
  "ending": {
    "ending_normal": {
      // 普通结局
    },
    "ending_complete": {
      // 完整探索结局
    }
  }
}
```
